The first release of go-whistle, a pure-Go port of Cactus Compute's
[Whistle](https://huggingface.co/Cactus-Compute/whistle): 55M parameters, 16.9 MB packed, en, de, fr, es, it, nl and
pl. No cgo and no Python at runtime; it runs straight from the packed 2/4-bit `whistle.cact` (weights 2.0.0,
`b358ddad`).

## What works

- **CLI** `whistle`: `download` (the pinned files, SHA-256 checked, resumable), `doctor`, `transcribe` (language
  detection or `--language`, `--keywords`, `--depth 2..8`, `--word-timestamps`, `--json` with the engine's JSON),
  `stream` (audio of any length from a file or raw PCM on stdin), `embed` (JSON or `.npy`) and `serve` (HTTP
  `POST /transcribe` and a WebSocket `/stream`).
- **Go API**, package `github.com/cwbudde/go-whistle/whistle`: `Load`/`LoadBytes`, `Transcribe`/`TranscribeWAV`,
  `NewStream` with `Process`/`Stop`, and `Embed`; results marshal to the engine's JSON byte for byte.
- **Web demo** at https://cwbudde.github.io/go-whistle/: the library as js/wasm in a Web Worker, for files and the
  microphone. Nothing leaves the tab.

## Parity with the engine

Measured against the closed-source Needle 3 engine 3.2.0 as a black-box oracle, with the default packed weights.
Sources are in [`docs/FINDINGS.md`](https://github.com/cwbudde/go-whistle/blob/v0.1.0/docs/FINDINGS.md) and
[`bench/RESULTS.md`](https://github.com/cwbudde/go-whistle/blob/v0.1.0/bench/RESULTS.md).

| What                                                    | go-whistle             | Finding      |
| ------------------------------------------------------- | ---------------------- | ------------ |
| Transcript and language equal to the engine's, 32 clips | 31/32                  | F-031, F-044 |
| Keyword cases equal to the engine's                     | 47/53                  | F-044        |
| Depth ladder 2–7 equal to the engine's                  | 161/192                | F-030, F-044 |
| Stream calls with the engine's decision                 | 797/930                | F-036, F-044 |
| LibriSpeech test-clean subset (200 utterances), WER     | 5.35 % (engine 5.30 %) | F-031, F-040 |
| `Embed` vs `needle_embed`, mean per-frame cosine        | 0.999827               | F-037        |
| Word start and end within 80 ms of the engine's         | 97.4 % of 459 words    | F-033        |

## Limits

- **30 s per call** for `transcribe`, `Transcribe` and `Embed`, as in the engine; a stream has no limit.
- **WAV input** is integer PCM; IEEE float WAVs are rejected.
- **Speed:** slower than the engine. On an Apple M5 Pro the median TTFT over the 32 clips is 18.8 ms against the
  engine's 6.9 ms, decode 1085 against 1499 tok/s (F-040). On amd64 the float GEMMs still run in pure Go, and there
  is no x86 benchmark yet (PLAN.md 12.3).
- **js/wasm** runs on one thread without SIMD: about 25 tok/s and a TTFT of 0.3–0.8 s under Node (F-043).
- Six keyword cases still differ from the engine, among them `de-paare-missed` (F-042, F-044).

## Install

```bash
go install github.com/cwbudde/go-whistle/cmd/whistle@v0.1.0
whistle download   # the model into models/whistle
whistle doctor
```

Or take a prebuilt `whistle` for linux/amd64, linux/arm64, darwin/arm64 or windows/amd64 from the assets below and
check it against `SHA256SUMS`. The library: `go get github.com/cwbudde/go-whistle/whistle@v0.1.0`.
